# useSortableList

List-agnostic reorder state management hook. Returns a `SortableListHandle` that you wire to `SortableContainer`, `SortableItem`, and your list component.

## Import

```tsx
import { useSortableList } from 'react-native-drax';
```

## Usage

```tsx
const sortable = useSortableList({
  data: items,
  keyExtractor: (item) => item.id,
  onReorder: ({ data }) => setItems(data),
});
```

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | auto-generated | DraxView id for the container |
| `data` | `T[]` | **required** | Array of items |
| `keyExtractor` | `(item: T, index: number) => string` | **required** | Unique key per item |
| `onReorder` | `(event: SortableReorderEvent<T>) => void` | **required** | Called after reorder |
| `horizontal` | `boolean` | `false` | Horizontal list layout |
| `numColumns` | `number` | `1` | Number of columns (grid) |
| `reorderStrategy` | `SortableReorderStrategy` | `'insert'` | `'insert'` or `'swap'` |
| `longPressDelay` | `number` | `250` | ms before drag activates |
| `lockToMainAxis` | `boolean` | `false` | Lock drag to list's main axis |
| `autoScrollJumpRatio` | `number` | `0.2` | Auto-scroll jump as fraction of container |
| `autoScrollBackThreshold` | `number` | `0.1` | Back auto-scroll threshold |
| `autoScrollForwardThreshold` | `number` | `0.9` | Forward auto-scroll threshold |
| `animationConfig` | `SortableAnimationConfig` | `'default'` | Animation preset or custom config |
| `getItemSpan` | `(item: T, index: number) => GridItemSpan` | — | Grid span per item (enables mixed-size grid). Only used when `numColumns > 1`. |
| `getItemLayout` | `(key: string) => SortableItemLayout \| undefined` | — | Where the list component places a row: `{ offset, length }` along the main axis. For virtualized lists, see [below](#virtualized-lists-getitemlayout). Single-column lists only. |
| `inactiveItemStyle` | `ViewStyle` | — | Style applied to all non-dragged items during drag |
| `draggedItemStyle` | `StyleProp<ViewStyle>` | `{ opacity: 0 }` | Style of the dragged item's in-list placeholder while its hover copy moves. Replaces the default. The placeholder stays at its pickup slot until release. Visual props only; pass a stable style |
| `itemEntering` | `EntryOrExitLayoutType` | — | Reanimated layout animation for items entering the list |
| `itemExiting` | `EntryOrExitLayoutType` | — | Reanimated layout animation for items exiting the list |
| `onDragStart` | `(event: SortableDragStartEvent<T>) => void` | — | Drag started |
| `onDragPositionChange` | `(event: SortableDragPositionChangeEvent<T>) => void` | — | Position changed |
| `onDragEnd` | `(event: SortableDragEndEvent<T>) => void` | — | Drag ended |

## Return Value: `SortableListHandle<T>`

| Property | Type | Wire To |
|---|---|---|
| `data` | `T[]` | List `data` prop |
| `onScroll` | scroll handler | List `onScroll` prop |
| `onContentSizeChange` | size handler | List `onContentSizeChange` prop |
| `stableKeyExtractor` | `(item: T, index: number) => string` | List `keyExtractor` prop |
| `_internal` | `SortableListInternal<T>` | Used by SortableContainer and SortableItem |

## Wiring Example

```tsx
const sortable = useSortableList({ data, keyExtractor, onReorder });

<SortableContainer sortable={sortable} scrollRef={listRef}>
  <FlatList
    ref={listRef}
    data={sortable.data}
    keyExtractor={sortable.stableKeyExtractor}
    onScroll={sortable.onScroll}
    onContentSizeChange={sortable.onContentSizeChange}
    renderItem={({ item, index }) => (
      <SortableItem sortable={sortable} index={index}>
        <ItemCard item={item} />
      </SortableItem>
    )}
  />
</SortableContainer>
```

## Virtualized Lists: `getItemLayout`

Drax measures the rows it can see. A virtualized list mounts only the rows near the viewport, so the rows outside it are unmeasured, and a row that was unmounted keeps the measurement it had then. Slot detection, neighbour shifts and the snap target need every row.

With `getItemLayout` the list component supplies what Drax cannot measure. It is called with a row's key and returns where the list has laid that row out:

- `offset`: start of the row along the main axis, in the list's own content coordinates. Any origin works: when a drag starts, Drax aligns the offsets with the dragged row's measurement.
- `length`: size of the row along the main axis, without the gap to the next row. Used only while the row has no measurement.

Return `undefined` for a row the list knows nothing about; that row then counts with its own measurement, if it has one.

From drag start on, every row's main-axis position comes from `getItemLayout`. Report layout positions in the order of `sortable.data` (where the list component has placed the rows), not the order on screen after a reorder the parent has not echoed yet. The function is called for every row on each drag update, so keep it cheap.

Keep the dragged row mounted while the list scrolls (its gesture ends when it unmounts), for example with a pinned or always-rendered row if the list component offers one.
