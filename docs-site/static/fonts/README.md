# Self-hosted fonts

These woff2 files are the subsets Google Fonts CSS2 served to a modern Chrome
user agent on 23 Nov 2026 for:

https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;600&family=Space+Grotesk:wght@400;500;600;700&display=swap

IBM Plex Mono v23 is included as static weights 400, 500 and 600, each in the
cyrillic-ext, cyrillic, symbols2, vietnamese, latin-ext and latin subsets.
Space Grotesk v22 is included as one variable font (weight axis 300–700) per
vietnamese, latin-ext and latin subset. The bytes are the files at
fonts.gstatic.com that the CSS above references.
